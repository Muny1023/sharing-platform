# 资源以"外链帖子"形式存在，MVP 不做文件上传

项目从纯登录/注册系统扩展为资源分享社区。用户所说的"分享资源"有多种可能形态（外链、文件上传、网盘），我们决定 MVP 阶段**资源只以 `http(s)` 外链形式存在**：帖子 = 标题 + 纯文本正文 + 一个链接。

## 为什么

- **文件上传牵一发动全身**：存储路径、大小限制、静态资源服务、下载鉴权、CDN，全都要单独设计。外链零成本，直接聚焦"社区"本身。
- **符合用户预期**：用户明确认可"先做 MVP"，分享的是网盘/在线地址，不是托管文件。
- **后置决策**：文件上传作为第二阶段独立功能，到时候加 `db_asset` 表和上传接口即可，不影响帖子/评论结构。

## 范围边界（MVP 明确不做）

- 不做审核，登录即可发布
- 不加管理员角色
- 不编辑评论（只允许删除自己的评论），允许编辑自己的帖子

## 备选方案

- **文件上传**：已否决，见上。
- **Markdown/富文本**：已否决。纯文本够用，渲染层无 XSS 面（Vue 默认转义），后续想加也是独立增强。
